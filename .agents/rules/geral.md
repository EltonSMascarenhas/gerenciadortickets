# WORKFLOW GLOBAL

Objetivo:
Maximizar qualidade, minimizar consumo de tokens e evitar redundância.

Regras Gerais

- Não execultar comandos via shell ou terminal.
- Trabalhe sempre sobre o estado atual do projeto.
- Nunca regenere arquivos completos quando apenas parte deles mudou.
- Prefira diffs ou trechos modificados.
- Preserve arquitetura, padrões e convenções existentes.
- Não repita contexto, requisitos ou documentação já estabelecidos.
- Não explique código, a menos que seja solicitado.
- Apenas instrua a execução e inicio do servidor local
- Gere somente os arquivos e trechos necessários para a tarefa.
- Não crie código duplicado.
- Reutilize componentes existentes sempre que possível.
- Mantenha respostas objetivas e focadas na tarefa atual.
- Faça perguntas apenas quando uma informação essencial estiver ausente.
- Considere decisões anteriores como válidas até que sejam alteradas.
- Evite exemplos fictícios, comentários excessivos e texto desnecessário.
- Priorize desempenho, legibilidade e manutenibilidade do código.
- Informe apenas os impactos relevantes das alterações realizadas.
